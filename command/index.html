    HuHoBot 命令列表¶

    权限列 管理员 受群配置的「管理方式」影响（/管理方式）：默认仅数据库管理员；可切换为 QQ 群主/管理员判定或双重要求。

    参数约定：(必选) [可选]

    如输入的名称带有空格，请使用英文双引号 " 包裹

    Note

    新版已取消/执行命令，可使用 /关键词 参数1 参数2 直接执行

    如果执行者拥有管理员权限，则自动使用原先的/管理员执行

    ℹ️ 帮助¶

    命令 参数 说明 权限
    /帮助 [文档/管理/指令/快速开始] 发送对应帮助图片或文档入口二维码 所有人

    👥 管理员管理¶

    命令 参数 说明 权限
    /管理方式 [QQ/手动/双重] 查看/切换本群管理员判定方式（QQ=QQ群主/管理员，手动=数据库管理员，双重=两者都要） 管理员
    /加管理 (OpenId/@提及) 将指定用户添加为数据库管理员 管理员
    /删管理 (OpenId/@提及) 将指定用户从数据库管理员移除 管理员
    /查管理 (OpenId/@提及) 查询指定用户是否为数据库管理员 管理员

    ⚙️ 白名单管理¶

    命令 参数 说明 权限
    /添加白名单 (XboxId) 向绑定服务器发送添加白名单请求 管理员
    /删除白名单 (XboxId) 向绑定服务器发送删除白名单请求 管理员
    /查白名单 [页码/关键字] 查询绑定服务器的白名单列表 管理员

    🖥️ 服务器管理¶

    命令 参数 说明 权限
    /绑定 (serverId) [多群] 发起群与服务器的绑定；无参查看当前绑定 绑定：管理员；查看：所有人
    /解绑 [serverId] 无参弹出选择框；有参直接解除指定服务器绑定 管理员
    /设置服务器 [serverId] 无参弹出服务器选择框；有参直接打开指定服务器操作面板 管理员
    /命名服务器 (serverId) (名称) 重命名已绑定的服务器 管理员

    📊 服务器状态查询¶

    命令 参数 说明 权限
    /查在线 — 查询绑定服务器的在线玩家列表 所有人
    /在线服务器 — 查询当前群可见的已连接服务器列表 所有人
    /motd [地址] [端口] 查询指定服务器的 MOTD 信息（受 blockMotd 屏蔽影响） 所有人

    🛡️ MOTD 控制¶

    命令 参数 说明 权限
    /blockMotd — 屏蔽本群的 MOTD 功能 管理员
    /unblockMotd — 解除本群的 MOTD 屏蔽 管理员

    🛠️ 命令执行¶

    命令 参数 说明 权限
    /执行 (关键词) [参数...] 以普通身份执行服务端自定义命令 所有人
    /管理员执行 (关键词) [参数...] 以管理员身份执行服务端自定义命令 管理员
    /执行命令 (命令内容) 向绑定服务器发送管理员命令并等待回报 管理员

    💬 群服互通¶

    命令 参数 说明 权限
    /发信息 (消息内容) 将消息转发到绑定服务器的游戏聊天 所有人
    /设置名称 (昵称) 设置自己的群服互通昵称 所有人
    /设置名称 (昵称) (OpenId) [强制] 管理员为他人设置/锁定昵称 管理员
    /全量 [开/关] 查看/开关全量转发模式（开启后所有未命中指令的消息自动转发到游戏） 管理员

    🔐 身份认证¶

    命令 参数 说明 权限
    /认证 — 查看自己的 QQ 认证绑定状态 所有人
    /认证 (QQ号) 发起 QQ 头像自助认证 所有人
    /认证 (QQ号) (OpenId) 管理员手动完成认证绑定 管理员
    /解除认证 (OpenId) 解除指定用户的 QQ 认证绑定 管理员
    /查信息 — 查看自己的 OpenId 和群 OpenId 所有人
    /查信息 (OpenId/@提及) 查询指定用户的 QQ 绑定信息 管理员

    🧩 扩展管理¶

    命令 参数 说明 权限
    /附属插件 — 查看已安装的扩展列表及其命令数 所有人
